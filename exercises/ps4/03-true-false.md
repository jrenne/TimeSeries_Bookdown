## Statement

State whether each assertion is true or false and briefly justify your answer. Let $x_t=x_{t-1}+\varepsilon_t$, where $\varepsilon_t\overset{i.i.d.}{\sim}\mathcal N(0,1)$, when the assertion refers to “the random walk.”

1. $\operatorname{Var}_t(x_{t+h})\to\infty$ as $h\to\infty$.
2. $x_t$ is not covariance stationary, but $\Delta x_t$ is.
3. If $\Delta^2x_t$ is $I(0)$ and $\Delta x_t$ is $I(1)$, then $x_t$ is $I(2)$.
4. The random walk is $I(1)$.
5. The random walk necessarily has unconditional mean zero.
6. In a regression of one unrelated $I(1)$ variable on another, usual stationary OLS standard errors give valid confidence intervals.
7. The OLS slope in a finite-sample regression of the random walk on its lag and a constant is typically biased downward.
8. If $x_t$ is $I(1)$ and $y_t$ is $I(2)$, then $x_t+y_t$ is generally $I(2)$.
9. If $x_t$ is $I(2)$ and $y_t$ is $I(1)$, the residual from regressing $x_t$ on $y_t$ is necessarily $I(1)$.
