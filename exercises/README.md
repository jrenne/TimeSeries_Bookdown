# Problem sets and past exams

The public course contains the statements for PS1–PS4 and the seven true/false questions from the 2024 exam. Hints and solutions are deliberately stored outside this repository in `Macroeconometrics/Exercises/Instructor_materials/TimeSeries_Bookdown` and are included only by the private build script.

The Markdown edition was checked against the original LaTeX/PDF problem sets and the R/exams sources for the 2024 exam. Corrections made during migration include AR-root calculations, the exponential-MLE information matrix, the Wald statistic, AR($p$) variance estimation, several Wold coefficients, the Newey–West arithmetic, the innovation in the cointegrating relation, and the explanation of the unstable ARMA factor in question 5 of the 2024 exam. The original files remain unchanged as an archive.
