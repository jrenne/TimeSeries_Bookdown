## Statement

A covariance-stationary process has $\gamma_0=4$, $\gamma_1=3$, $\gamma_2=1$, and $\sum_{h=3}^{\infty}\gamma_h=2$. Let $\bar y_T=T^{-1}\sum_{t=1}^T y_t$ and $\mathbb E(y_t)=\mu$.

State whether each assertion is true or false and justify your answer.

1. $\operatorname{Var}(y_t+y_{t-1})=14$.
2. $\operatorname{Var}(y_{t-1})=\gamma_1$.
3. For large $T$, $\sqrt T(\bar y_T-\mu)$ is approximately $\mathcal N(0,16)$.
4. For large $T$, $\operatorname{Var}[\sqrt T(\bar y_T-\mu)]$ is approximately 4.
5. If $T=1600$ and $\bar y_T=1$, then 0.70 lies in an approximate 95% confidence interval for $\mu$.
